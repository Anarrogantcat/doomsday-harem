feat: 防御与事件系统 v0.14.0

新增 systems/defense.ts（536 行，纯函数式）
- 9 种事件类型：野兽侵扰 / 零星丧尸 / 流浪者乞讨 / 侦察者 /
  丧尸潮 / 匪帮突袭 / 变异兽 / 军方残部 / 全面围攻
- 每种事件有起始天数、权重、强度、数量范围、可谈判/可威慑标记
- 防御等级：由设施防御、预警、掩体、自动火力、护盾、巡逻岗位、
  在岗人数、主角属性八项加权计算
- 五级防御：基础 / 初级 / 中级 / 高级 / 要塞级
- 安全指数与夜间遇袭概率（防御越高概率越低）
- 可抵御强度阈值
- 事件判定：基础概率受夜间倍率、名声、血腥值影响；按权重选类型；
  强度 ±15% 波动；防御足够高时自动威慑退去
- 结算：五种结果（击退/被突破/谈判解决/威慑退去/自行撤离）
  - 我方战力 = 主角 + 同伴 + 防御工事 + 自动火力
  - 弹药消耗、伤亡、围墙破损、物资损失、战利品
  - 匪帮/围攻突破时可能掳走同伴
- 声望系统：名声（引来匪帮与军方）与血腥值（引来丧尸），
  战后变化与每日自然衰减
- 手动触发（测试与作弊器）、确定性随机可复现
- JSON 序列化
