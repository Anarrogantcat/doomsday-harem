### N-1 设计要点

**姓氏来源**：玩家输入的主角姓名（如「林晓」→ 姓「林」）

**名字池现状**（`packages/core/src/systems/names.ts`）

| 项 | 数量 |
|---|---|
| 风格 | 6 类（御姐 / 少女 / 母亲 / AI / 通用女性 / 敌对） |
| 单字名（去重） | 168 |
| 双字名（去重） | 162 |
| **名字合计** | **330** |
| 单姓 | 100 |
| 复姓 | 24（欧阳 / 司马 / 上官 / 诸葛…） |
| 娘家姓池 | 30 |

**已实现函数**
```
splitName(name)          拆姓与名（支持单姓/复姓/英文/空输入）
surnameOf(name)          取姓
shortSurname(name)       取短姓（复姓取第二字）
generateName(style,seed) 生成带姓的完整名
generateGivenName(...)   只生成名
familyNames(heroName)    生成全家名字（姐姐/妹妹/母亲/AI）
offspringName(hero,idx)  生成后代名
randomName(seed,style)   给 NPC 取名
namePoolStats()          池子规模统计
```

**示例输出**（主角「林晓」）
```
姐姐   林苓
妹妹   林豆蔻
母亲   裴云霞  ← 娘家姓「裴」
AI     林泠泠  ← 随主角姓
```

**「扶她」的处理（已定）**
- 扶她是**生理性别**，不是名字、不是身份标签
- **不显示在名字旁边**（名字旁只放气质 / 体型这类描述）
- 只在角色的「生理」字段里显示
- 数据上挂在 `physiology.sex`，与角色名完全无关

**名字旁只放名字（已定）**

用户明确：**名字旁边不需要任何属性标签**，气质（御姐）、体型（178cm/D）
这类信息都归到该去的地方。

```
右栏抬头    林晓                ← 只有名字
详情抬头    林晓                ← 只有名字
详情标签    预知能力 / 基地建造者 / 隐藏天才   ← 只放「特性」

生理分组    生理性别  扶她       ← 生理信息统一放这里
            性别认同  女性
            性取向    女          ← 主角只对女性有兴趣
            身高      178cm
            体重      62kg
            三围      90-62-92
            罩杯      D
            体型      高挑御姐
```

**生理区块必须对所有角色生效**

踩过的坑：同伴详情的状态页由 `fillDetail()` 动态重写，
写死在 HTML 里的「生理」区块会被冲掉 —— 结果只有主角有。
必须放进渲染函数（`physiBlock()`）里，按角色数据生成。

**分类原则**
| 信息类型 | 放哪 |
|---|---|
| 名字 / 称谓 | 抬头（旁边不放属性） |
| 气质、体型、生理 | 生理分组 |
| 特性、能力 | 详情标签行 |
| 关系定位（主导方/照顾方） | 抬头，跟称谓并列 |

**不随名字变化的（保持通用表述）**
```

跟随 主角                          ← 这是关系描述
主角怀孕后…                        ← 这是规则文案
```
