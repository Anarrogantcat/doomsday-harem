## 零、原型真实结构（逐块核实）

### 0.1 顶层：`#game` 是 7 列 grid

```css
#game {
  position: fixed; inset: 0;
  grid-template-columns:
    var(--c-left) var(--sp) minmax(0,1fr) var(--sp) var(--c-right) var(--sp) var(--c-detail);
  grid-template-rows: 1fr auto;
}
```

顺序：**左栏 · 分隔 · 中栏 · 分隔 · 右栏 · 分隔 · 详情栏**，底部横跨一行 `.strip`。

### 0.2 左栏 `.left` —— 3 个一级子元素

| 序 | 元素 | 内容 |
|---|---|---|
| 1 | `.block` | **基地核心**：`.aicard`（AI 头像 + 名 + 好感/忠诚条） |
| 2 | `.block` | **后宫**：`.bhead`（含 `3 / 20` 计数）+ `.hlist`（`.hitem` 卡）+ `.lrow`（未解锁 17 位） |
| 3 | `.qpanel` | **快捷操作**：`.qhead`（‹ 1/3 ›）+ `.qgrid` + `.qdots` + `.qfoot` |

`.hitem` 内部：`img` + `.hi`（`.hn` 名+Lv / `.hj` 岗位 / `.bars` 好感·欲情条）

### 0.3 中栏 `.center` —— **5 个**一级子元素

| 序 | 元素 | 内容 |
|---|---|---|
| 1 | `.ctabs` | **只有 2 个标签**：`叙事` / `战斗` + 右侧提示「视图随操作自动切换」 |
| 2 | `.stage` | `.stitle` 标题 + `.smeta` 参与者 + 多个 `.beat`（`.bnum` + `.ln`/`.ln mind`/`.ln speech`） |
| 3 | `.obar` | **选项区**：`.ohint`（`.ohl`+ `.ohk`）+ `.olist`（`.opt`，含 `.opt go` / `.opt lock`） |
| 4 | `.eventbar` | **事件栏**：`.eb-grip` + `.eb-head`（`.eb-title`/`.eb-count`/`.eb-btn`）+ `.eb-list`（`.eb-entry`，含 `.alert`） |
| 5 | `.ibar` | **输入栏**：`.imodes`（模式 + `.itoggle`）+ `.ibody`（`.irow` + input） |

⚠️ **我之前搞错的三处**：
1. ❌ 以为中栏有「叙事/剖面/战斗」三标签 → **实际只有 2 个**
2. ❌ 以为「剖面」在中栏 → **实际是弹窗**（`#fortress-view`，从右栏「基地」打开）
3. ❌ `.obar`/`.eventbar`/`.ibar` 顺序 → **实际是 选项→事件→输入**（我把输入栏放到页面底部了）

### 0.4 右栏 `.right` —— 2 个一级子元素

| 序 | 元素 | 内容 |
|---|---|---|
| 1 | `.rtabs` | **只有 3 个标签**：`地图` / `基地` / `房车` |
| 2 | `.rpane` | 地图页内容 |

⚠️ **关键**：`基地` 和 `房车` **不切页，是 onclick 打开弹窗**（`openFortress()` / `openVehicle()`）。

`.rpane` 内容顺序：
```
.obj        当前目标（.objh/.objt/.objd/.objp + .objbar/.objpct）
.dvd        分隔线
.sec        地图标题行（名字 + ⇄ + ▤ + ⤢）
.mgrid      5x5 小地图
.dpad       方向键（↑ ← ◆ → ↓）
.curcell    当前格（.cc-n/.cc-d/.cc-t）
.dvd
.sec        外出行动
.actlist    4 个 .act-btn（远征/巡逻/搜刮/侦查）
.dvd
.sec        交通方式
```

### 0.5 详情栏 `.detail-side` —— 5 个一级子元素

| 序 | 元素 | 内容 |
|---|---|---|
| 1 | `.ds-hero` | **主角段（固定顶部）** |
| 2 | `.ds-divider` | 分隔 |
| 3 | `.ds-head` | **同伴段头** |
| 4 | `.ds-body` | 同伴段体 |
| 5 | `.ds-acts` | 同伴段操作按钮 |

**主角段内部**：`.ds-head.hero`（`.ds-name` + `.ds-expand` ⤢）
+ `.ds-body`（`.ds-portrait` → `.ds-info`（`.ds-title`/`.ds-tags`/`.ds-lvl`）
+ `.ds-bars`（**6 条**：体力/饥饿/口渴/精力/心情/欲情）
+ `.ds-grid`（`.dsg`：战力/可加点/科技/设施/同伴…））
+ `.ds-acts`
