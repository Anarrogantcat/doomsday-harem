## 批次 H · Electron 打包（2 天）★ 最后一步

### H-1 迁移原因（已确认）

```
起因  火绒（HipsTray/HipsDaemon）为主 + Defender SmartScreen + 国产杀软
痛点  Tauri：Rust 外壳 + 运行时自解压 → 撞「自解压+写文件」高危特征
      NSIS 安装器本身也是误报高发对象
      无代码签名（证书一年数千）→ 无信誉背书
目的  产物结构接近主流 Electron 应用，吃大厂白样本信誉
```

### H-2 新建文件

```
apps/desktop/electron/
  main.cjs       主进程（窗口 / 单实例 / IPC）
  preload.cjs    桥接（暴露安全 API）
apps/desktop/electron-builder.yml
```

### H-3 electron-builder.yml（asar 保持默认 true）

```yaml
appId: com.doomsdayharem.app
productName: DoomsdayHarem
copyright: 免费 · 禁售 · 禁商用 · 禁直播录播 · 署名「染喵」
# asar 保持默认（true）—— 不写这一行

directories:
  output: dist-electron
  buildResources: build

files:
  - dist/**/*
  - electron/**/*
  - package.json
  - '!node_modules/**/*'      # 省 100+ MB

win:
  target:
    - target: nsis
      arch: [x64]
    - target: portable
      arch: [x64]
  icon: build/icon.ico
  artifactName: ${productName}-${version}-${arch}.${ext}

nsis:
  oneClick: false
  perMachine: false
  allowToChangeInstallationDirectory: true
  createDesktopShortcut: true
  createStartMenuShortcut: true
  shortcutName: DoomsdayHarem         # 不可含 / （会渲染乱码）
  deleteAppDataOnUninstall: false

portable:
  artifactName: ${productName}-${version}-portable.${ext}
```

### H-4 从 Tauri 迁移的四处

| Tauri 侧 | Electron 侧 |
|---|---|
| `src-tauri/src/save.rs`（AES-256-GCM + HMAC-SHA256） | Node `crypto` 重写 |
| Tauri FS 插件（Mod 加载） | Node `fs` |
| `tauri.conf.json` 窗口配置 | `BrowserWindow` 选项 |
| 单实例（Tauri 内置） | `requestSingleInstanceLock()` —— **必须进程第一件事** |

### H-5 抄经验不抄配置（参考项目踩过的坑）

| 坑 | 我们的做法 |
|---|---|
| asar 打包 EBUSY（bd2 踩到） | 它的特例（为绕坑关 asar），**我们保持默认 true** |
| `release` 目录被 Windows 锁 | 输出目录用 `dist-electron` 独立命名 |
| `shortcutName` 含 `/` 渲染乱码 | 用纯英文 |
| 双开导致双托盘双缓存 | 单实例锁 |
| `node_modules` 被打进包（138MB） | `files` 显式排除 |

### H-6 打包与验证

```bash
pnpm --filter @doomsday/desktop exec electron-builder --win
# 产物：dist-electron/DoomsdayHarem-<version>-x64.exe（NSIS）
#       dist-electron/DoomsdayHarem-<version>-portable.exe
```
