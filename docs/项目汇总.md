## 八、界面

### 四栏布局（可拖动调宽）
```
名册(9-34em) │ 叙事 │ 地图(13-44em) │ 详情栏(11-34em)
```
- 三条分隔条可拖，宽度存 localStorage，双击/Ctrl+0/按钮恢复默认
- 响应式：<1160 隐详情 / <1000 隐名册 / <820 隐地图

### 中栏（叙事）
叙事文本 → **选项区** → 事件记录（可拖动高度）→ 输入栏（可隐藏）

### 选项区
| 图标 | 类型 | 触发 |
|---|---|---|
| ▶ | 继续 | 空格 |
| 💬 | 对话 | 数字键 |
| 🤔 | 判定 | 数字键 |
| ✍ | 行动 | 数字键 |
| 🔒 | 锁定（灰显+条件） | — |

### 左侧栏
AI 核心 / 后宫名册（单击→详情栏，双击→弹窗）/ 快捷操作（3 页 36 按钮）

### 最右详情栏
上部主角（固定，8 操作按钮）+ 下部选中角色

### 弹窗
- 主角详情 / 同伴详情：6 标签 + 8 按钮
- 着装子标签：**装备与服装分离**
- 自慰子页 / 后庭准备 6 步
- 要塞剖面 / 房车详情 / 大地图

## 十二、关键技术约束

| 约束 | 说明 |
|---|---|
| `erasableSyntaxOnly` | 禁 `enum`、命名空间、构造器参数属性 |
| `NodeNext` | import 必须带 `.ts` 后缀 |
| 核心零 IO | `packages/core` 纯逻辑，状态可 JSON 序列化 |
| 确定性随机 | mulberry32，战斗 RNG 用 `day*100000+minute*10+round` |
| 存档加密 | AES-256-GCM + HMAC-SHA256（Rust） |
| session.ts 保护 | 任何编辑后必须验证行数（~3800 行） |
