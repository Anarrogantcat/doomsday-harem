# 安装与安全提示

> 更新于 v0.64.0 —— 已从 Tauri 迁到 Electron。

## 为什么换成 Electron

此前用 Tauri 打包，产物是「Rust 外壳 + 运行时自解压」结构。
这个结构撞上了杀毒软件的「**自解压 + 写文件**」高危特征，
火绒（HipsTray / HipsDaemon）误报率最高，其次是 Defender SmartScreen。

Electron 的 `app.asar` 是**单文件归档**，不触发自解压特征，
产物结构与 VS Code / Slack / Discord 同构，能吃到主流白样本信誉。

---

## 首次运行会看到什么

打开 exe 时可能出现：

> **无法验证发布者。你确定要运行此软件吗？**

**这不是报毒**，是 Windows 对**未签名程序**的标准确认框。

原因：本项目没有购买代码签名证书（一年数千元）。
点「运行」即可，之后不再提示。

## 产物说明

| 文件 | 用途 | 说明 |
|---|---|---|
| `DoomsdayHarem-<版本>-x64.exe` | 安装版（NSIS） | 可自选安装目录 |
| `DoomsdayHarem-<版本>-portable.exe` | 便携版 | 单文件免安装，**误报率更低** |

**建议优先用便携版** —— 没有安装器，少一个误报面。

## 如果被拦截

### 火绒
主界面 → 防护中心 → 查看拦截记录 → 找到被拦文件 → 点「信任」

或：设置 → 病毒防护 → 信任区 → 添加 → 选择游戏目录

### Windows Defender
安全中心 → 病毒和威胁防护 → 保护历史记录 → 找到文件 → 「允许在设备上」

### 「已阻止」标记（从网络下载时）
右键 exe → 属性 → 常规 → 勾选「解除锁定」→ 确定

## 存档位置

Electron 版存档在这里（`%APPDATA%\.doomsday-harem\` 之类由 app.getPath 决定）：

```
<用户数据目录>\data\saves\<槽位>.sav
```

加密方式：**AES-256-GCM + HMAC-SHA256**，格式 `[12B nonce][16B tag][密文]`。

> 注意：**Tauri 时代的旧存档（`%LOCALAPPDATA%\com.doomsdayharem.app\`）
> 与 Electron 版密钥相同**（种子固定为 `doomsday-harem-v1-save-key`），
> 把 `.sav` 文件拷到新目录即可继续使用。

## 开发说明

```bash
pnpm --filter @doomsday/desktop dev            # 浏览器预览（Vite）
pnpm --filter @doomsday/desktop electron:dev   # Electron 开发模式
pnpm --filter @doomsday/desktop dist           # 打包（NSIS + portable）
```

**asar 保持默认（true）** —— 这是抗误报的关键，不要关。
