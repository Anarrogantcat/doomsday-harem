Doomsday Harem 被安全软件拦截的处理方法
==========================================

【为什么会报毒】

本程序没有购买代码签名证书（一年数千元），
Windows 和杀毒软件对「未签名 + 会写文件 + 自解压」的程序
会做启发式判定，误报率较高。

常见误报来源：
  · 火绒（HipsTray / HipsDaemon）—— 主因
  · Windows Defender SmartScreen —— 首次运行提示
  · 其他国产杀软的行为拦截

程序本身不做任何危险操作：不联网上传、不改注册表关键项、
不装驱动、不自启、不开后门。


【方法一：火绒加白名单（推荐）】

1. 打开火绒安全
2. 右上角「≡」→ 设置
3. 左侧选「病毒防护」
4. 找到「信任区」→ 点「添加」
5. 选择「目录」，把游戏整个文件夹加进去
6. 确定

也可以：火绒主界面 → 防护中心 → 查看拦截记录 →
找到被拦的文件 → 点「信任」

临时关闭（不推荐，仅测试用）：
  火绒主界面 → 防护中心 → 右上角总开关


【方法二：用便携版（无需安装）】

解压 DoomsdayHarem_<版本>_portable.zip 到任意目录，
双击 DoomsdayHarem.exe 即可。

便携版没有安装器，只有一个 exe，
被杀软误报的概率明显低于 NSIS 安装包。


【方法三：Windows Defender】

如果弹出「Windows 已保护你的电脑」：
  点「更多信息」→「仍要运行」

如果被 Defender 隔离：
  Windows 安全中心 → 病毒和威胁防护 → 保护历史记录 →
  找到该文件 →「允许在设备上」

永久排除：
  Windows 安全中心 → 病毒和威胁防护 → 管理设置 →
  排除项 → 添加或删除排除项 → 添加文件夹


【方法四：解除文件锁定】

从网络下载的文件会被打上「已阻止」标记：
  右键 exe → 属性 → 常规 → 勾选「解除锁定」→ 确定


【方法五：自己签名（技术用户）】

可以用自签名证书给 exe 签名，
虽然不能完全消除误报，但能改善：
  · 用 New-SelfSignedCertificate 生成证书
  · 用 signtool 签名 exe
  · 把证书导入「受信任的根证书颁发机构」

注意：自签名对火绒这类启发式引擎效果有限，
真正解决需要购买 OV/EV 代码签名证书。


【验证程序安全性】

想确认 exe 没被篡改，可以：
1. 查看数字签名（预计显示「无签名」，这是正常的）
2. 用 virustotal.com 上传扫描，看是否只有少数引擎误报
3. 检查文件大小是否与发布说明一致
