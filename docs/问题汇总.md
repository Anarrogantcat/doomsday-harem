### ⚠️ 需要裁决的冲突（3 处）

#### 冲突 1 · L-1 vs L-7

```
L-1（已定）  主角被俘期间禁止性内容
L-7（本轮）  主角可与女性敌人发生性关系，主角被榨精
```

| 解读 | L-1 调整为 | 理由 |
|---|---|---|
| **A · 收紧为「禁同伴被侵犯」**（倾向） | 改为禁**同伴**被侵犯；主角自己与敌人的性内容允许 | L-1 本意是防**视角反转 NTR**；主角参与的没有「自己的女人被抢走」痛点 |
| **B · 保留 L-1，榨精另设场景** | 不变 | 榨精只能发生在**非被俘状态**（主动潜入 / 遭遇战后主动行为） |

#### 冲突 2 · INV-7 白名单需要三类

```ts
// L-9 后（两类）
const allowed = new Set([hero.id, ...companions.map(c => c.id)]);

// L-7 + L-10/L-11 后（三类）
const allowed = new Set([
  hero.id,
  ...companions.map(c => c.id),
  ...enemies.map(e => e.id)       // ← 新增
]);
```

**关键约束**：敌人参与的性场景**必须包含主角**。

```
✅ 主角 ↔ 女性敌人    允许（L-7）
✅ 后宫 ↔ 后宫        允许（L-9）
❌ 敌人 ↔ 同伴        禁止 —— 这才是 NTR
❌ 敌人 ↔ 敌人        禁止（无主角参与）
```

#### 冲突 3 · L-4 处女规则是否适用于敌人

```
L-4  非人妻后宫全为处女；人妻最多 3 人
     ↑ 原文只写「后宫」
```

| 选项 | 说明 |
|---|---|
| ① 适用（建议） | 敌人也是存活者，未与主角发生过关系前为处女；与 L-8「全员出众」同理 |
| ② 不适用 | 敌人可设定为有过经历（匪帮成员等） |
