## 二、批次 1 · 地基（✅ 已完成，v0.63.0）

**为什么排第一**：15 条铁律、8 条不变式、23 个功能开关若只存在文档里，
后续每加一条就要改 5 个文件。先把**注册表**建起来，后面全是填数据。

| # | 交付 | 文件 | 行数 |
|---|---|---|---|
| 1 | 铁律与不变式注册表 | `packages/core/src/systems/laws.ts` | 464 |
| 2 | 功能开关注册表 | `packages/core/src/systems/featureFlags.ts` | 356 |
| 3 | 存档迁移链 | `packages/core/src/save/migrate.ts` | 200 |
| 4 | 测试 | 3 个测试文件 | 564 |

**已实现的关键能力**

```
laws.ts
  LAWS              15 条铁律（可查询、可筛分类/状态）
  INVARIANTS         9 条不变式（含待落地的 INV-7/INV-8）
  checkParticipants      INV-7 三类白名单校验（敌人×同伴 = NTR）
  checkCaptiveRule       L-1 被俘规则（同伴禁、主角放行）
  checkPartnerFate       L-2 措辞检查（「失踪」被拦）
  checkPartnerHistoryLimit  L-4 上限 3 人
  scanForbiddenTerms     禁止词扫描（供 ntr-guard 测试）

featureFlags.ts
  FEATURE_FLAGS     23 个开关，带依赖链
  isFlagOn          读取时求值（父关子灭，数据不动）
  shadowedFlags     列出被父项遮住的开关
  loadFlags/saveFlags  localStorage 适配

migrate.ts
  MIGRATIONS        显式迁移链（当前空）
  migrateSave       逐级应用，链断则拒绝
  migrateSaveLenient 宽容模式（尽量救回存档）
  validateMigrationChain  自检环/跳号
```

**验收**：1361 项测试全通过，typecheck 无错误。

## 九、给未来更新的接口（本次新增）

### 9.1 新增一条铁律

```ts
// packages/core/src/systems/laws.ts
export const LAWS: LawDef[] = [
  // ... 现有 15 条
  {
    id: "L-16", name: "新铁律名称",
    rule: "完整语义",
    category: "dominance",
    status: "decided",
    targets: ["文件:行"],
    invariants: ["INV-x"]
  }
];
```
测试 `lawIdGaps()` 会**自动发现跳号/重号**。

### 9.2 新增一个开关

```ts
// packages/core/src/systems/featureFlags.ts
export const FEATURE_FLAGS: FlagDef[] = [
  // ... 现有 23 个
  {
    key: "dh-new",
    name: "新玩法",
    desc: "说明",
    category: "nsfw",
    def: true,
    requires: ["dh-nsfw"],   // 自动继承父开关
    laws: ["L-16"]
  }
];
```
UI 会**自动渲染**出这个开关，无需改界面代码。

### 9.3 新增一次存档迁移

```ts
// packages/core/src/save/migrate.ts
export const MIGRATIONS: Migration[] = [
  {
    from: 1, to: 2,
    desc: "新增关系服从度字段（L-12 调教）",
    migrate: (d) => ({
      ...d,
      relations: d.relations.map((r) => ({ ...r, submission: 0 }))
    })
  }
];
```
同时 `version.ts` 的 `SCHEMA_VERSION` 改为 2。
测试 `validateMigrationChain()` 会检查链是否走得通。

### 9.4 新增一条不变式

在 `INVARIANTS` 里加一条，若有校验逻辑则在 `laws.ts` 里加对应的 `checkXxx()` 函数。
