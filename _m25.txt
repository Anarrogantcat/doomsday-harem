feat: 程序化全身立绘 v0.29.0

背景
调研了 Kenney.nl 的免费素材（CC0），结论是**没有合适的整身人物立绘**：
- blocky-characters 是 3D FBX 模型（需要渲染管线）
- pixel-platformer 是科幻/平台跳跃题材（角色与题材不符）
- roguelike-characters 是分层装备素材（只有头部可用）

因此改为**程序化全身立绘** —— 比静态贴图更好，因为能反映真实状态。

新增 packages/core/src/render/rig.ts
- 解剖比例基准（约 6.5 头身）：
  头 0.150 / 颈 0.025 / 肩→腰 0.175 / 腰→胯 0.095 /
  胯→膝 0.255 / 膝→踝 0.235 / 脚 0.040
- 宽度：肩 0.165 / 腰 0.105 / 胯 0.160（随体型变化）
- 分层绘制：背景 → 后发 → 腿 → 胯 → 躯干 → 胸 → 孕肚 →
  臂 → 内衣 → 外衣 → 颈 → 头 → 前发 → 表情 → 角标

按真实数据驱动：
- 身高（150-185cm）→ 画面占比
- 体型 → 肩宽/腰宽/胯宽/胸围
- 怀孕 → 孕肚大小随进度（上限胯宽 0.9 倍，含肚脐与高光）
- 着装 → 逐件判断覆盖度，皮肤/布料按实际切换
- 暴露度 → 显示在角标
- 心情 → 嘴形（笑/平/苦）
- 欲情 → 眼神半睁 + 腮红 + 张口
- 性格 → 站姿（主动型外扩 / 内敛型内收）
- 扶她 → 胯部轮廓
- 名字 → 散列出稳定色相（发色/肤色/衣色）

新增 buildFromText()：把角色数据里的体型描述文字转成数值
- 关键词映射（丰腴 +0.22 / 纤细 -0.18 / 蜂腰翘臀 +0.10）
- 罩杯解析（A-H → 每级 0.055）
- 腰臀比解析（相对 0.7 加权）

UI 接入
- Portrait 组件新增 mode="full"，用 data URI 内联 SVG
- 角色详情面板改用全身立绘（104×182）
- 名册仍用像素头像（小尺寸下更清晰）
