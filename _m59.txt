v0.59.0：生育履历按角色区分

问题
- 所有同伴的「累计怀孕 / 累计生产」都显示 0
- 母亲已经生过姐姐、主角、妹妹，不该是 0

改动
- COMPANIONS 增加 preg 字段
    { state 当前状态, stage 孕程, count 累计怀孕,
      births 累计生产, children 已育子女, recover 产后恢复 }
- 各角色取值
    姐姐   0 / 0 / 0    （26 岁，未生育）
    母亲   3 / 3 / 3    （生过姐姐、主角、妹妹）
    妹妹   0 / 0 / 0    （19 岁，处女）
- 新增 pregBlock(d) 按数据渲染生育区块
- 生育力 > 0 时追加提示「她已经是 N 个孩子的母亲」
- 母亲的生理期由「正常」改为「不规律」（45 岁）

验证（逐个点开）
  姐姐  累计怀孕 0 次 · 累计生产 0 次 · 已育子女 0
  母亲  累计怀孕 3 次 · 累计生产 3 次 · 已育子女 3
        提示：她已经是 3 个孩子的母亲
  妹妹  累计怀孕 0 次 · 累计生产 0 次 · 已育子女 0
- 0 个异常
