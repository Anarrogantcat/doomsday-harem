v0.50.0：侧栏可拖动调宽

布局
- 四栏网格改为 7 列（4 内容列 + 3 分隔条）
- 分隔条可拖动调整相邻栏宽
  名册 9-34em　地图 13-44em　详情栏 11-34em
- 拖动时全局光标变 col-resize 且禁用文本选中
- 分隔条悬停/拖动变紫色，中央有握把标记

持久化
- 栏宽存入 localStorage（键 dh-col-widths）
- 重载后自动恢复
- 三种恢复方式：双击分隔条 / Ctrl+0 / 底栏「↺ 默认栏宽」按钮
- 拖动结束弹出提示显示当前宽度

响应式兼容
- 媒体查询改为只调整 CSS 变量，不再改网格模板
- <1160px 隐藏详情栏及其分隔条
- <1000px 隐藏名册及其分隔条
- <820px 隐藏地图及其分隔条

修复
- 分隔条误设 grid-row:1 导致自动排布错位（左栏内容被挤到 5px 列）
- splitter 与事件栏握把的 setPointerCapture 未做异常保护

验证（1920x1080）
- 默认 [336, 448, 336]（名册/地图/详情）
- 拖左栏 246 → 重载后仍 246 → 恢复默认 336
- 拖地图 448 → 576
- 全部 3 条分隔条可见可拖
- 1208 项测试通过，TypeScript 干净
