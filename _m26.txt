feat: UI 全面重构 v0.30.0（参考 TiTS 设计语言）

参考对象
分析了 TiTS（Trials in Tainted Space）0.9.159 的 UI 实现，
从其打包代码中提取出 51KB 完整样式表，总结出设计语言：

配色体系
- 深蓝底 #3D5174 / 面板 #333E52 / #2C3649
- 单一高亮色 #8D31B0（紫），辅以语义色：
  正 #0CD71C / 负 #FF0000 / 警 #E8C815 / 信息 #00F5EF
- 状态色分组：护盾 #00CCFF / 生命 #00CC2F / 欲望 #FF00F0 / 能量 #FFD207

关键设计手法
- 全部尺寸用 em 相对单位（可整体缩放）
- 面板用左侧色条而非边框区分类型
- 按键角标统一为圆角小方块
- 信息层级靠明度区分，不靠边框粗细

按本作需求重排为四栏
1. 左栏·后宫名册
   - 主角与特殊AI 置顶（独立配色：主角紫、AI 青）
   - 21 位后宫卡片，左侧色条标识状态
   - 头像改为全身立绘裁切
   - 夜袭预警角标
2. 中栏·舞台
   - 三视图 Tab（叙事/要塞剖面/战斗）
   - 叙事区含欢迎页（首次进入显示世界观）
   - 下侧栏：像素场景条（Canvas 程序化绘制）
3. 右栏·世界面板
   - 四个 Tab：地图 / 基地 / 房车 / 行动
   - 地图：可达区域列表（含距离/耗时/危险度）+ 交通方式 + 已发现区域
   - 基地：三层设施概览 + 建造进度
   - 房车：燃料/电量/车况 + 已装改装
   - 行动：时间推进 / 区域操作 / 防御 / 状态
4. 最右·角色详情
   - 主角或同伴的完整档案
   - 全身立绘（8.5em × 15em）
   - 六项生存值 + 关系条 + 操作按钮

立绘增强（性别与身材可辨识）
- 新增 cup 参数（0-7 罩杯）直接控制胸部体积
- 新增 whr 参数（腰臀比）控制腰细臀宽
- 胸部加下缘阴影与乳沟（罩杯 ≥ 3 时）
- 扶她轮廓明确化：阴囊 + 阴茎 + 龟头 + 高光
- 躯干改为沙漏型（肋部收窄 + 腰部内收阴影）
- 胯部加臀线与臀沟阴影
- 大腿根部加饱满曲线
- 新增 buildFromText：把角色数据的体型描述文字
  （如「成熟丰腴型，E-cup，腰臀比 0.7」）转成数值

像素场景条
- Canvas 程序化绘制当前地点的像素景观
- 天空渐变随时间变化（清晨/正午/黄昏/夜晚 + 星空）
- 地形剪影按类型生成（城市/森林/山地/水域）
- 角色像素小人：有胸腰腿区分，身高/怀孕/罩杯影响形态
- 无需素材文件，随地点与时间实时变化

设置联动
- 字号设置驱动根 em，整体缩放
- 紧凑模式（名册小头像）
- 生成噪音日志过滤（库存/存档类不进叙事区）
